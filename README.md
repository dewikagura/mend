mend is one command-line tool that applies AI-written edits in four formats — unified diffs with wrong line numbers, SEARCH/REPLACE blocks, V4A patches, and JSON tool calls — to a tree of files, tolerating whitespace and indentation drift, and changing every file or none. It scores 1000/1000 on the kit's public practice set.

## Run it

```sh
node main.ts [options] [PATCH]
```
